◆ lmmc_fft_radix4()

lmmc_status_t lmmc_fft_radix4 ( lmmc_real_t * real,
lmmc_real_t * imag,
size_t n,
int inverse )

严格 radix-4 就地 FFT.

对长度为 4 的幂的复数序列执行快速傅里叶变换.变换结果就地写回输入数组. 逆变换时自动除以 N 进行归一化.

参数
[in,out]real实部数组,长度 n ;变换后就地覆盖为频域实部.
[in,out]imag虚部数组,长度 n ;变换后就地覆盖为频域虚部.
[in]nFFT 长度,必须为 4 的幂.
[in]inverse非 0 时执行逆变换并归一化(除以 n).
返回
LMMC_STATUS_OK 表示成功; LMMC_STATUS_INVALID_ARGUMENT 表示 n 位于 4 的幂集合之外或指针为 NULL.
副作用
  • 就地修改 real 和 imag 数组的全部 n 个元素.
  • 不分配堆内存.
  • real 和 imag 不可指向重叠的内存区域.

被这些函数引用 lmmc_fft(), lmmc_fft_radix4(), lmmc_fft_radix4_forward() , 以及 lmmc_fft_radix4_inverse().

lmmc_real_t * out )

误差函数 erf(x) - 使用 C 标准库 erf() 并包装为 LMMC 接口.

计算误差函数 \(\mathrm{erf}(x) = \frac{2}{\sqrt{\pi}} \int_0^x e^{-t^2} dt\) .

C99 标准库提供了高精度的 erf 实现(通常 < 1 ULP 误差), 直接使用以确保最佳精度.
