◆ lmmc_double_nearly_equal_tol()

lmmc_status_t lmmc_double_nearly_equal_tol ( lmmc_real_t a,
lmmc_real_t b,
lmmc_real_t abs_tol,
lmmc_real_t rel_tol,
int * out_equal )

同时考虑绝对与相对容差的近似相等判定.

判定条件: \(|a-b| \le \max(\mathrm{abs\_tol},\; \mathrm{rel\_tol}\cdot\max(|a|,|b|))\) .

参数
[in]a第一个比较值.
[in]b第二个比较值.
[in]abs_tol绝对容差(>= 0).
[in]rel_tol相对容差(>= 0).
[out]out_equal输出比较结果:1 表示近似相等,0 表示不等.
返回
LMMC_STATUS_OK 成功; LMMC_STATUS_INVALID_ARGUMENT 若 out_equal 为 NULL 或容差为负.
注解
不分配内存，输入保持原值。
