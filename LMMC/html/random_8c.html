◆ ZIG_N

#define ZIG_N   256

Ziggurat normal sampler (256 rectangles)

Reference: Marsaglia & Tsang, "The Ziggurat Method for Generating Random Variables", JSS 2000.

Tables are built for the right half of the standard normal (x >= 0). The sampler generates |x| and applies a random sign.

Table layout: zig_xtab[0] = v/f(r) (width of base strip including tail) zig_xtab[1] = r (tail cutoff) zig_xtab[i] for i=2..255: decreasing x-coordinates zig_xtab[256] = 0 (peak of distribution)

For 256 rectangles: r = 3.6541528853610088 v = 0.00492867323399 (area of each rectangle in the half-normal)

◆ lmmc_rng_create()

lmmc_status_t lmmc_rng_create ( lmmc_rng_t ** out_rng)

创建随机数发生器实例。

分配并初始化一个 xoshiro256** 发生器。句柄由调用方拥有，默认 线程受限；跨线程传递或并发访问必须由调用方同步。并行工作负载应为 每个线程创建独立句柄，或使用 lmmc_rng_clone 和 ::lmmc_rng_jump。

参数
[out]out_rng输出新创建的 RNG 句柄。
返回
LMMC_STATUS_OK 成功； LMMC_STATUS_INVALID_ARGUMENT 若 out_rng 为 NULL； LMMC_STATUS_ALLOCATION_FAILED 若内存分配失败。
副作用
  • 分配堆内存存储 RNG 内部状态，调用方必须调用 lmmc_rng_destroy 释放。

将平台熵混入默认种子,为各随机数发生器建立独立数据流.

生成 Gamma 分布样本 \(\mathrm{Gamma}(\alpha, \beta)\) 。

使用 Marsaglia-Tsang 方法（shape >= 1），shape < 1 时使用 \(X = Y \cdot U^{1/\alpha}\) 变换法（Y ~ Gamma(1+α, β)）。

参数
[in]rng已初始化的 RNG。
[in]shape形状参数 \(\alpha\) （> 0）。
[in]scale尺度参数 \(\beta\) （> 0）。
[out]out输出样本值。
返回
LMMC_STATUS_OK 成功； LMMC_STATUS_INVALID_ARGUMENT 若 shape <= 0、scale <= 0 或指针为 NULL。
副作用
  • 就地修改 rng 的内部状态（消耗多个随机数，次数不确定）。
  • 不分配堆内存。

lmmc_status_t lmmc_rng_int_uniform ( lmmc_rng_t * rng,
int64_t lo,
int64_t hi,
int64_t * out )

在 [lo, hi] 闭区间内生成无偏均匀整数分布样本。

支持完整的 int64_t 定义域且不执行有符号溢出；lo == hi 时不消耗 RNG 状态。

参数
[in]rng已初始化的 RNG。
[in]lo下界（含）。
[in]hi上界（含）。
[out]out输出样本值。
返回
LMMC_STATUS_OK 成功；LMMC_STATUS_INVALID_ARGUMENT 若 lo > hi。
