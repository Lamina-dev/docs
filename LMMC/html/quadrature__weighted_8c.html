◆ LMMC_GH_MAX_ORDER

#define LMMC_GH_MAX_ORDER   20

Gauss-Hermite 求积，权函数 exp(-x^2)，积分域 (-inf, +inf)。

Golub-Welsch 算法以 Hermite 多项式的对称三对角 Jacobi 矩阵特征值为节点， 以特征向量的首分量计算权重。 物理学家形式的 Hermite 多项式满足 x H_n = H_{n+1}/2 + n H_{n-1}； Jacobi 系数为 a_i = 0、b_i = sqrt(i/2)，i=1..n-1。

#define LMMC_GL_LAG_MAX_ORDER   20

Gauss-Laguerre 求积，权函数 exp(-x)，积分域 [0, +inf)。

Golub-Welsch 算法使用首一 Laguerre 多项式的三项递推： x L_n(x) = L_{n+1}(x) + (2n+1) L_n(x) - n^2 L_{n-1}(x)。 Jacobi 系数为 alpha_i = 2*i + 1、beta_i = i（i=1..n-1）； mu_0 为 exp(-x) 在 [0, inf) 上的积分，等于 1。

Gauss-Hermite 求积：权函数 \(\exp(-x^2)\) ，积分域 \((-\infty, +\infty)\) 。

计算 \(\int_{-\infty}^{+\infty} f(x) \exp(-x^2) dx\) 。

参数
[in]f被积函数（不含权函数部分）。
[in]ud用户数据指针。
[in]order节点数（阶数），范围 [1, 20]。
[out]out积分结果值。
返回
LMMC_STATUS_OK 成功； LMMC_STATUS_NUMERICAL_FAILURE 回调或累加结果为非有限值； LMMC_STATUS_INVALID_ARGUMENT 若 order 超出范围或指针为 NULL。
副作用
  • 回调 f 被调用恰好 order 次。
  • 不分配堆内存。
