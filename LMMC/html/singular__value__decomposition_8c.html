◆ lmmc_svd()

lmmc_status_t lmmc_svd ( const lmmc_mat_t * a,
lmmc_svd_result_t * out_result )

计算奇异值分解:A = U * Σ * V^T.

算法:Householder 双对角化 -> Golub-Kahan 隐式 QR 迭代. 奇异值按降序排列.

参数
[in]amxn 矩阵(不被修改).
[out]out_result输出 U(mxm),sigma(min(m,n)),Vt(nxn). 调用方需配对调用 lmmc_svd_result_destroy 释放.
返回
  • LMMC_STATUS_OK - 成功.
  • LMMC_STATUS_INVALID_ARGUMENT - 指针为 NULL.
  • LMMC_STATUS_CONVERGENCE_FAILED - 迭代未收敛.
  • LMMC_STATUS_ALLOCATION_FAILED - 内存分配失败.
副作用
  • 分配堆内存.a 不被修改.

◆ lmmc_pinv()

lmmc_status_t lmmc_pinv ( const lmmc_mat_t * a,
lmmc_real_t tol,
lmmc_mat_t * out_pinv )

计算 Moore-Penrose 伪逆 A^+.

内部通过 SVD 实现:A^+ = V * Σ^{-1}_trunc * U^T, 其中奇异值 < tol * sigma_max 的被截断为零.

参数
[in]amxn 矩阵(不被修改).
[in]tol奇异值截断阈值;<=0 时使用 max(m,n)*eps*sigma_max.
[out]out_pinvnxm 输出矩阵,须已创建.
返回
  • LMMC_STATUS_OK - 成功.
  • LMMC_STATUS_INVALID_ARGUMENT - 指针为 NULL.
  • LMMC_STATUS_DIMENSION_MISMATCH - out_pinv 维度与 nxm 不匹配.
  • LMMC_STATUS_ALLOCATION_FAILED - 内存分配失败.
副作用
  • 覆写 out_pinv->data.内部分配并释放 SVD 工作空间.
