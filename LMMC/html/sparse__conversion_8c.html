◆ lmmc_sparse_from_dense()

lmmc_status_t lmmc_sparse_from_dense ( const lmmc_mat_t * dense,
lmmc_real_t eps,
lmmc_sparse_mat_t * out_sparse )

由稠密矩阵生成 CSR 稀疏矩阵,绝对值 <= eps 的元素被丢弃.

两遍扫描:第一遍计数 nnz,第二遍填充数组.

参数
[in]dense输入稠密矩阵(不被修改).
[in]eps丢弃阈值(非负).
[out]out_sparse输出 CSR 矩阵,调用方需配对调用 lmmc_sparse_destroy 释放.
返回
  • LMMC_STATUS_OK - 成功.
  • LMMC_STATUS_INVALID_ARGUMENT - 指针为 NULL 或 eps < 0.
  • LMMC_STATUS_ALLOCATION_FAILED - 内存分配失败.
副作用
  • 分配堆内存.dense 不被修改.

lmmc_status_t lmmc_sparse_to_dense ( const lmmc_sparse_mat_t * sparse,
lmmc_mat_t * out_dense )

将稀疏矩阵展开为稠密矩阵(缺失项填 0).

out_dense 必须已创建且维度与 sparse 一致.先清零再填入非零元.

参数
[in]sparse输入稀疏矩阵(不被修改).
[out]out_dense输出稠密矩阵,内容被完全覆写.
返回
  • LMMC_STATUS_OK - 成功.
  • LMMC_STATUS_INVALID_ARGUMENT - 指针为 NULL 或结构非法.
  • LMMC_STATUS_DIMENSION_MISMATCH - 维度不匹配.
副作用
  • 覆写 out_dense->data.无内存分配.
