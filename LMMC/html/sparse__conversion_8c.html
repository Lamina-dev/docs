由稠密矩阵生成 CSR，丢弃绝对值 <= eps 的元素。

参数
[in]dense输入稠密矩阵，保持不变。
[in]eps非负丢弃阈值。
[out]out_sparse输出 CSR，调用方须用 lmmc_sparse_destroy 释放。
返回
  • LMMC_STATUS_OK - 成功。
  • LMMC_STATUS_INVALID_ARGUMENT - 指针为 NULL 或 eps < 0。
  • LMMC_STATUS_ALLOCATION_FAILED - 内存分配失败。
注解
两遍扫描分别计数 nnz 和填充新分配的数组。
