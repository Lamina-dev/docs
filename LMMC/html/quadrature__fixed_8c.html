复合梯形公式：将 \([a,b]\) 等分为 n 段。

采样点在 [-1,1] 的归一化坐标中生成，并通过溢出安全的中心和半长度 映射到 [a,b]；不会直接形成可能溢出的 b-a。

参数
[in]func被积函数回调。
[in]user_data传递给 func 的用户上下文。
[in]a积分下限。
[in]b积分上限。
[in]n子区间数（>= 1）。
[out]out_result输出积分近似值。
返回
LMMC_STATUS_OK 成功； LMMC_STATUS_INVALID_ARGUMENT 若端点非有限、顺序无效、 n == 0 或指针为 NULL。
副作用
  • 回调 func 被调用 n+1 次。
  • 不分配堆内存。

复合 Simpson 公式：将 \([a,b]\) 等分为 n 段（要求偶数）。

采样点先在 [-1,1] 的归一化坐标中生成，再通过溢出安全的中心和半长度 映射到 [a,b]；不会直接形成可能溢出的 b-a。

参数
[in]func被积函数回调。
[in]user_data传递给 func 的用户上下文。
[in]a积分下限。
[in]b积分上限。
[in]n子区间数（必须为偶数且 >= 2）。
[out]out_result输出积分近似值。
返回
LMMC_STATUS_OK 成功； LMMC_STATUS_INVALID_ARGUMENT 若 n 为奇数、n == 0 或指针为 NULL。
副作用
  • 回调 func 被调用 n+1 次。
  • 不分配堆内存。
