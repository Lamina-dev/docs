◆ lmmc_mat_gemm()

lmmc_status_t lmmc_mat_gemm ( lmmc_real_t alpha,
const lmmc_mat_t * A,
int transA,
const lmmc_mat_t * B,
int transB,
lmmc_real_t beta,
lmmc_mat_t * C )

通用矩阵-矩阵乘法(GEMM): \(C \leftarrow \alpha \cdot \mathrm{op}(A) \cdot \mathrm{op}(B) + \beta \cdot C\)。

op(X) = X(transX==0)或 X^T(transX!=0)。 设 op(A) 为 MxK,op(B) 为 KxN,则 C 必须为 MxN。 使用内置分块三重循环实现，块大小为 64。

参数
[in]alpha标量乘子 alpha。
[in]A输入矩阵 A(不被修改)。
[in]transA非零表示对 A 取转置。
[in]B输入矩阵 B(不被修改)。
[in]transB非零表示对 B 取转置。
[in]beta标量乘子 beta.beta==0 时 C 的旧值被忽略(可含 NaN)。
[in,out]C输出矩阵,维度须为 MxN.C 不可与 A 或 B 别名。
返回
  • LMMC_STATUS_OK - 成功。
  • LMMC_STATUS_INVALID_ARGUMENT - 指针为 NULL、存储包络溢出，或 C 与 A/B 重叠。
  • LMMC_STATUS_DIMENSION_MISMATCH - op(A) 的列数 != op(B) 的行数,或 C 维度不匹配； 维度错误优先于重叠检查。
注解
不分配内存。

◆ lmmc_mat_gemv()

lmmc_status_t lmmc_mat_gemv ( lmmc_real_t alpha,
const lmmc_mat_t * A,
int transA,
const lmmc_vec_t * x,
lmmc_real_t beta,
lmmc_vec_t * y )

通用矩阵-向量乘法(GEMV): \(y \leftarrow \alpha \cdot \mathrm{op}(A) \cdot x + \beta \cdot y\)。

op(A) 为 MxN 时,要求 x->size==N,y->size==M。 y 的半开存储包络不得与 A 或 x 的存储包络重叠。

参数
[in]alpha标量乘子 alpha。
[in]A输入矩阵 A(不被修改)。
[in]transA非零表示对 A 取转置。
[in]x输入向量 x(不被修改)。
[in]beta标量乘子 beta.beta==0 时 y 的旧值被忽略。
[in,out]y输出向量,长度须为 op(A) 的行数，且不得与 A 或 x 重叠。
返回
  • LMMC_STATUS_OK - 成功。
  • LMMC_STATUS_INVALID_ARGUMENT - 指针为 NULL、存储包络溢出或输出重叠。
  • LMMC_STATUS_DIMENSION_MISMATCH - 向量长度与矩阵维度不匹配（优先于重叠检查）。
注解
不分配内存。

◆ lmmc_vec_cross()

lmmc_status_t lmmc_vec_cross ( const lmmc_vec_t * a,
const lmmc_vec_t * b,
lmmc_vec_t * c )

计算三维向量叉积: \(c = a \times b\)。

公式:

  • \(c_0 = a_1 b_2 - a_2 b_1\)
  • \(c_1 = a_2 b_0 - a_0 b_2\)
  • \(c_2 = a_0 b_1 - a_1 b_0\)

支持别名(c 可与 a 或 b 为同一向量),内部使用临时变量计算。

参数
[in]a输入向量(不被修改),长度必须为 3。
[in]b输入向量(不被修改),长度必须为 3。
[out]c输出向量,长度必须为 3,内容被覆写。
返回
  • LMMC_STATUS_OK - 成功。
  • LMMC_STATUS_INVALID_ARGUMENT - 指针为 NULL。
  • LMMC_STATUS_DIMENSION_MISMATCH - 任一向量长度不为 3。
注解
不分配内存。
