详细描述

数值常量、特殊值、近似比较与基本数学补充函数。

此模块包含 IEEE-754 特殊值生成 / 检测、扩展三角与对数函数、 浮点拆分、近似相等判定，以及一个轻量的 radix-4 FFT 与 Lambert W 函数。

◆ lmmc_double_nearly_equal_tol()

lmmc_status_t lmmc_double_nearly_equal_tol ( lmmc_real_t a,
lmmc_real_t b,
lmmc_real_t abs_tol,
lmmc_real_t rel_tol,
int * out_equal )

同时考虑绝对与相对容差的近似相等判定。

判定条件： \(|a-b| \le \max(\mathrm{abs\_tol},\; \mathrm{rel\_tol}\cdot\max(|a|,|b|))\) 。 适用于数值计算中需要同时处理接近零和远离零的数值比较场景。

参数
[in]a第一个比较值。
[in]b第二个比较值。
[in]abs_tol绝对容差（>= 0）。
[in]rel_tol相对容差（>= 0）。
[out]out_equal输出比较结果：1 表示近似相等，0 表示不等。
返回
LMMC_STATUS_OK 成功； LMMC_STATUS_INVALID_ARGUMENT 若 out_equal 为 NULL 或容差为负。
副作用
