◆ lmmc_fft_radix4()

lmmc_status_t lmmc_fft_radix4 ( lmmc_real_t * real,
lmmc_real_t * imag,
size_t n,
int inverse )

对长度为 4 的幂的复数序列执行就地 radix-4 FFT。

参数
[in,out]real实部数组,长度 n ;变换后就地覆盖为频域实部.
[in,out]imag虚部数组,长度 n ;变换后就地覆盖为频域虚部.
[in]nFFT 长度,必须为 4 的幂.
[in]inverse非 0 时执行逆变换并归一化(除以 n).
返回
LMMC_STATUS_OK 表示成功; LMMC_STATUS_INVALID_ARGUMENT 表示 n 位于 4 的幂集合之外、指针为 NULL、数组重叠或数组存储范围的地址计算溢出.
注解
不分配堆内存；两数组各覆写 n 个元素，写入前检查并拒绝重叠。

引用了 lmmc_fft_radix4() , 以及 LMMC_STATUS_INVALID_ARGUMENT.

被这些函数引用 lmmc_fft(), lmmc_fft_radix4(), lmmc_fft_radix4_forward() , 以及 lmmc_fft_radix4_inverse().
