◆ lmmc_mat_det()

lmmc_status_t lmmc_mat_det ( const lmmc_mat_t * a,
lmmc_real_t * out_det )

计算方阵行列式(基于内部 LU 分解).

内部分配临时工作空间进行 LU 分解,不修改输入矩阵. 对 1x1 和 2x2 矩阵有特化快速路径.

参数
[in]a输入方阵(不被修改).
[out]out_det输出行列式值.奇异矩阵时 *out_det = 0.
返回
  • LMMC_STATUS_OK - 成功(包括奇异情况,此时 *out_det==0).
  • LMMC_STATUS_INVALID_ARGUMENT - 指针为 NULL 或矩阵非方阵.
  • LMMC_STATUS_ALLOCATION_FAILED - 临时内存分配失败.
副作用
  • 分配并释放临时工作内存.输入矩阵不被修改.

lmmc_status_t lmmc_mat_inv ( const lmmc_mat_t * A,
lmmc_mat_t * A_inv )

计算方阵的逆矩阵.

内部通过 LU 分解 + 逐列求解 \(A \cdot \text{col}_i = e_i\) 实现. 若 A 奇异,返回 LMMC_STATUS_SINGULAR_MATRIX 且 A_inv 不被修改.

参数
[in]A输入方阵.
[out]A_inv输出逆矩阵,须已创建且与 A 同维.
返回
LMMC_STATUS_OK 成功;奇异返回 LMMC_STATUS_SINGULAR_MATRIX .

计算矩阵的数值秩(基于 SVD).

内部通过 lmmc_svd 计算奇异值,统计大于容差 tol 的奇异值个数. 当 tol <= 0 时,使用默认容差:max(rows, cols) * LMMC_REAL_EPSILON * sigma_0, 其中 sigma_0 为最大奇异值.

参数
[in]a输入矩阵(不被修改).

  • LMMC_STATUS_INVALID_ARGUMENT - 指针为 NULL.
  • LMMC_STATUS_ALLOCATION_FAILED - 内存分配失败.
  • LMMC_STATUS_CONVERGENCE_FAILED - SVD 迭代未收敛.
副作用
  • 内部分配并释放 SVD 工作空间.a 不被修改.

◆ lmmc_mat_pow()

lmmc_status_t lmmc_mat_pow ( const lmmc_mat_t * a,
int n,
lmmc_mat_t * out )

计算方阵的整数幂: \(\text{out} = A^n\).

使用二进制快速幂算法(重复平方法),乘法次数为 O(log|n|).

  • n=0 -> 单位矩阵.
  • n=1 -> 直接复制.
  • n<0 -> 先计算 A 的逆矩阵,再对逆矩阵求 |n| 次幂.

内部分配两个 nxn 临时矩阵用于迭代,返回前释放.

参数
[in]a输入方阵(不被修改).
[in]n整数指数,可为负,零或正.
[out]out输出矩阵,须已创建且与 a 同维(nxn).
返回
  • LMMC_STATUS_OK - 成功.
  • LMMC_STATUS_INVALID_ARGUMENT - 指针为 NULL,或矩阵非方阵,或 out 维度不匹配.
  • LMMC_STATUS_ALLOCATION_FAILED - 临时内存分配失败.
  • LMMC_STATUS_SINGULAR_MATRIX - n<0 且 A 奇异(不可逆).
副作用
  • 覆写 out->data.内部分配并释放临时工作矩阵.a 不被修改.

◆ lmmc_mat_rdiv()

lmmc_status_t lmmc_mat_rdiv ( const lmmc_mat_t * B,
const lmmc_mat_t * A,
lmmc_mat_t * X )

计算矩阵右除: \(X = B \cdot A^{-1}\).

通过转置系统求解:将问题转化为 \(A^T \cdot X^T = B^T\), 对 A^T 进行 LU 分解后逐列求解,最终得到 X.

要求 A 为方阵(nxn),B 的列数等于 A 的行数(即 B 为 mxn), X 的维度为 mxn.

参数
[in]B被除矩阵(mxn,不被修改).
[in]A除数方阵(nxn,不被修改).
[out]X输出矩阵(mxn),须已创建且维度为 (B->rows x A->cols).
返回
  • LMMC_STATUS_OK - 成功.
  • LMMC_STATUS_INVALID_ARGUMENT - 指针为 NULL,或 A 非方阵,或维度不匹配.
  • LMMC_STATUS_ALLOCATION_FAILED - 临时内存分配失败.
  • LMMC_STATUS_SINGULAR_MATRIX - A 奇异(不可逆).
副作用
  • 覆写 X->data.内部分配并释放临时工作矩阵.A,B 不被修改.
