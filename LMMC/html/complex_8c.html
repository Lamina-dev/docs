◆ lmmc_complex_exp()

lmmc_status_t lmmc_complex_exp ( const lmmc_complex_t * z,
lmmc_complex_t * out )

复数指数函数: \( e^z = e^x (\cos y + i \sin y) \),其中 \( z = x + iy \).

正常幅值直接计算；当实指数落在溢出或次正规数范围时，使用两个 \(e^{x/2}\) 因子，将三角因子纳入最终乘积后形成结果分量。 输出可以与输入共用存储；成功时写入完整结果，失败时保持输出不变。

参见
ISO C11 committee draft N1570, 7.3.7.1 (cexp). https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf
参数
[in]z输入复数.
[out]out输出 \( e^z \).
返回
  • LMMC_STATUS_OK - 成功.
  • LMMC_STATUS_INVALID_ARGUMENT - 任一指针为 NULL.
  • LMMC_STATUS_NUMERICAL_FAILURE - 输入或结果非有限.

z = x + iy 时,e^z = e^x * (cos(y) + i*sin(y)).

◆ lmmc_complex_log()

lmmc_status_t lmmc_complex_log ( const lmmc_complex_t * z,
lmmc_complex_t * out )

复数主值对数: \( \ln z = \ln(\operatorname{hypot}(x,y)) + i \arg(z) \).

最大分量绝对值位于 [0.5, 1] 时，实部通过补偿平方和计算 log1p(x*x + y*y - 1)/2，保留单位模附近的小量。 其他幅值使用 log(max(|x|,|y|)) + log1p(ratio^2)/2； 有限输入即使数学模超出 double 范围仍可返回有限对数。

当 z 的模为零时(即 z = 0+0i),返回域错误. 负实轴两侧由虚部的有符号零区分，主辐角分别为 \(+\pi\) 和 \(-\pi\)。 输出可以与输入共用存储；成功时写入完整结果，失败时保持输出不变。

参见
ISO C11 committee draft N1570, 7.3.7.2 (clog). https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf
参数
[in]z有限复数(模不可为零).
[out]out输出主值对数.
返回
  • LMMC_STATUS_OK - 成功.
  • LMMC_STATUS_INVALID_ARGUMENT - 任一指针为 NULL.
  • LMMC_STATUS_OUT_OF_RANGE - z 的模为零(对数无定义).
  • LMMC_STATUS_NUMERICAL_FAILURE - 输入或结果非有限.

Compensated squared modulus supplies the small argument of log1p. Ordered squares use FastTwoSum; FMA supplies product residuals. TwoSum carries the low-order terms through residual cancellation.

参见
Ogita, Rump, Oishi, "Accurate Sum and Dot Product" (2005), Algorithms 1.1 (FastTwoSum) and 3.5 (TwoProductFMA). https://doi.org/10.1137/030601818

◆ lmmc_complex_sqrt()

lmmc_status_t lmmc_complex_sqrt ( const lmmc_complex_t * z,
lmmc_complex_t * out )

采用缩放算法计算复数主值平方根.

即使有限实部与虚部对应的数学模超过可表示范围，只要平方根的两个 分量仍可表示，算法也通过输入尺度分解返回有限结果；同时避免 \(x^2+y^2\) 和 \(|z| \pm x\) 的中间溢出与相消。 虚部非零时，以其幅值除以大分量幅值的两倍得到小分量幅值。 该分母保持有限且非零；缩放因子在除法前合并，使次正规小分量只经历一次除法舍入。 结果实部为非负值（零取正零），虚部保留输入虚部的符号，包括有符号零。 输出可以与输入共用存储；成功时写入完整结果，失败时保持输出不变。

参见
ISO C11 committee draft N1570, 7.3.8.3 (csqrt). https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf
参数
[in]z有限复数.
[out]out输出主值平方根.
返回
  • LMMC_STATUS_OK - 成功.
  • LMMC_STATUS_INVALID_ARGUMENT - 任一指针为 NULL.
  • LMMC_STATUS_NUMERICAL_FAILURE - 输入或结果非有限.

有限双曲因子使用直接乘积；双曲因子溢出时，将主导指数项 分解为两个 \(e^{|y|/2}\) 因子，与三角因子共同形成结果分量。 输出可以与输入共用存储；成功时写入完整结果，失败时保持输出不变。

NIST DLMF, 4.28.1 and 4.28.2, hyperbolic exponential identities. https://dlmf.nist.gov/4.28

◆ lmmc_complex_pow()

lmmc_status_t lmmc_complex_pow ( const lmmc_complex_t * base,
const lmmc_complex_t * exp,
lmmc_complex_t * out )

复数幂: \( \text{base}^{\text{exp}} = e^{\text{exp} \cdot \ln(\text{base})} \).

先验证两个输入均为有限复数。非零底数的实整数指数使用二进制平方求幂， 负整数指数先取倒数；其他指数使用主值对数计算。 对零底数，本接口定义零次幂为 1+0i；指数实部为正时返回 0+0i； 指数实部为负或指数为非零纯虚数时返回域错误。 输出可以与任一输入共用存储；成功时写入完整结果，失败时保持输出不变。

参见
ISO C11 committee draft N1570, 7.3.8.2 (cpow), principal branch. https://www.open-std.org/jtc1/sc22/wg14/www/docs/n1570.pdf
参数
[in]base有限底数.
[in]exp有限指数.
[out]out输出幂值.
