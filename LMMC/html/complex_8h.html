详细描述

复数类型与运算模块。

本模块提供复数类型 lmmc_complex_t 及其基本算术运算（加、减、乘、除、 共轭、模、辐角）、极坐标构造、超越函数（exp、log、sqrt、sin、cos、pow）， 以及复数向量 lmmc_cvec_t 和复数矩阵 lmmc_cmat_t 的生命周期管理。

lmmc_status_t lmmc_complex_pow ( const lmmc_complex_t * base,
const lmmc_complex_t * exp,
lmmc_complex_t * out )

复数幂： \( \text{base}^{\text{exp}} = e^{\text{exp} \cdot \ln(\text{base})} \)。

当 base 的模为零且 exp 的实部为负时，返回域错误。 当 base = 0+0i 且 exp = 0+0i 时，按 cpow 惯例返回 1+0i。 当 base = 0+0i 且 exp 实部 > 0 时，返回 0+0i。

参数
[in]base底数（当模为零且指数实部为负时返回错误）。
[in]exp指数。
[out]out输出幂值。
返回
  • LMMC_STATUS_OK — 成功。
  • LMMC_STATUS_INVALID_ARGUMENT — 任一指针为 NULL。
  • LMMC_STATUS_OUT_OF_RANGE — base 模为零且 exp 实部为负。

内部通过 lmmc_alloc 分配 rows*cols 个 lmmc_complex_t 的连续缓冲区， stride 设为 cols（紧凑存储），所有实部和虚部初始化为 0，owns_data 置 1。

参数
[in]rows行数，必须 > 0。
[in]cols列数，必须 > 0。
[out]out输出矩阵结构体。调用方需配对调用 lmmc_cmat_destroy 释放。
返回
  • LMMC_STATUS_OK — 成功。
  • LMMC_STATUS_INVALID_ARGUMENT — rows 或 cols 为 0，或 out 为 NULL。
  • LMMC_STATUS_ALLOCATION_FAILED — 内存分配失败。
副作用
  • 分配堆内存（owns_data=1）。out 的所有字段被覆写。

void lmmc_cvec_destroy ( lmmc_cvec_t * vec)

销毁复数向量，释放其拥有的底层缓冲区。

若 vec->owns_data 非零，调用 lmmc_free 释放 vec->data； 否则仅将结构体字段清零。对 NULL 指针安全。

参数
[in,out]vec待销毁的复数向量，可为 NULL。
副作用
  • 若 owns_data：释放堆内存，vec->data 置 NULL，size 清零。
  • 若 !owns_data：仅清零结构体字段，不释放外部缓冲区。
  • 销毁后该向量不可再用于任何运算。
