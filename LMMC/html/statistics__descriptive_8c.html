◆ lmmc_vec_mean()

lmmc_status_t lmmc_vec_mean ( const lmmc_vec_t * x,
lmmc_real_t * out_mean )

计算向量样本均值 \(\bar{x} = \frac{1}{n}\sum_{i=1}^{n} x_i\) 。

使用在线均值更新；当 x-mean 溢出时切换到等价的有限凸组合，因此 只要最终均值可表示，就不会因为原始总和、极差或无关的方差溢出而失败。

参数
[in]x输入有限向量，size >= 1。
[out]out_mean输出均值。
返回
LMMC_STATUS_OK 成功； LMMC_STATUS_INVALID_ARGUMENT 若 x 为空向量或指针为 NULL； LMMC_STATUS_NUMERICAL_FAILURE 若输入包含非有限值。
副作用
  • 无。只读访问输入向量，不分配内存。

const lmmc_vec_t * y,

总体 Pearson 相关系数。

两列分别平移原点、按二进制缩放，再缩放中心偏差；以联合补偿累计 修正中心矩，在缩放域完成零分配计算。 常量列或非有限输入返回 ::LMMC_STATUS_NUMERICAL_FAILURE； 输出仅成功时写入，仅将舍入误差范围内的越界结果截断至 [-1,1]。

◆ lmmc_mat_covariance_sample()

lmmc_status_t lmmc_mat_covariance_sample ( const lmmc_mat_t * x,
lmmc_mat_t * out_covariance )

计算样本协方差矩阵（cols × cols），要求行数 >= 2 。

输出矩阵 out_covariance 的 (i,j) 元素为第 i 列与第 j 列的样本协方差。 使用 Bessel 校正（除以 rows-1）。

参数
[in]x输入矩阵，rows >= 2，每行为一次观测。
[out]out_covariance输出协方差矩阵，大小 cols × cols，调用方需预分配。
返回
LMMC_STATUS_OK 成功； LMMC_STATUS_INVALID_ARGUMENT 若 rows < 2、维度不匹配或指针为 NULL。
副作用
  • 就地写入 out_covariance 矩阵的全部元素。
  • 内部可能分配临时向量用于列均值计算，函数返回前释放。
