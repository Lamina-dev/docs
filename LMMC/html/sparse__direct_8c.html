struct lmmc_sparse_lu_t

稀疏 LU 分解上下文(不透明类型).

符号阶段在 A+A^T 的去重对称简单图上执行确定性的贪心残余度排序。 该排序只删除已消元顶点的关联边，不建模消元填充，因此不宣称为 AMD。 分解按符号分析、数值分解与求解三个阶段执行。

lmmc_status_t lmmc_sparse_lu_symbolic ( const lmmc_sparse_mat_t * a,
lmmc_sparse_lu_t ** out_lu )

稀疏 LU 符号分析阶段：去重简单图 + 贪心残余度重排序。

分析矩阵的稀疏结构，计算确定性的度数/原索引顺序，并预分配 L/U 因子的存储空间。分析结果可复用于多次数值分解 (当矩阵结构不变,仅数值变化时).

参数
[in]a输入方阵(不被修改),rows 须等于 cols.
[out]out_lu返回的 LU 上下文句柄,调用方需配对调用 lmmc_sparse_lu_destroy 释放.
返回
  • LMMC_STATUS_OK - 成功.
  • LMMC_STATUS_INVALID_ARGUMENT - 指针为 NULL 或矩阵非方阵.
  • LMMC_STATUS_ALLOCATION_FAILED - 内存分配失败.
副作用
  • 分配堆内存(LU 上下文 + 内部工作数组).a 不被修改.
  • 若 a 为 CSR 格式,内部会临时转换为 CSC 并在返回前释放.

lmmc_sparse_lu_t * lu )

使用稠密列工作区执行左看稀疏 LU 分解.

稀疏 LU 数值分解阶段（稠密列工作区左看算法 + 部分主元）。

每个置换后的输入列先散布到工作区,再由已存储的 L 列更新、选择主元, 最后压缩为稀疏 L 和 U.

使用稠密列工作区执行左看稀疏 LU 分解.

在已完成符号分析的 lu 上下文中执行数值分解。 每列散布到稠密工作区并由已有 L 列更新；矩阵数值变化但结构不变时可复用 lu。

参数
[in]a输入方阵(不被修改),维度须与符号分析时一致.
[in,out]lu已完成符号分析的 LU 上下文,数值因子被覆写.
返回
  • LMMC_STATUS_OK - 成功.
  • LMMC_STATUS_INVALID_ARGUMENT - 指针为 NULL 或维度不匹配.
  • LMMC_STATUS_SINGULAR_MATRIX - 主元为零,矩阵奇异.
  • LMMC_STATUS_ALLOCATION_FAILED - 因子数组扩容失败.
副作用
  • 修改 lu 内部的 L/U 数值数组和行置换.
  • 分配临时工作内存并在返回前释放.

lmmc_status_t lmmc_sparse_lu_solve ( const lmmc_sparse_lu_t * lu,
const lmmc_vec_t * b,
lmmc_vec_t * x )

使用残余度排序的 LU 因子求解 A*x = b.

利用已分解的稀疏 LU 因子求解 A*x = b.

分解满足 P*A*Q = L*U,其中 P 为部分主元行置换,Q 为残余度列置换.

使用残余度排序的 LU 因子求解 A*x = b.

求解过程:x = Q * U^{-1} * L^{-1} * P * b,其中 P 为行置换,Q 为残余度列置换. lu 必须已完成 symbolic + numeric 两阶段.

参数
[in]luLU 上下文(不被修改).
[in]b右端向量,长度须等于 lu->n.
[out]x解向量,长度须等于 lu->n,内容被覆写.
返回
  • LMMC_STATUS_OK - 成功.
  • LMMC_STATUS_INVALID_ARGUMENT - 指针为 NULL.
  • LMMC_STATUS_DIMENSION_MISMATCH - 向量长度与矩阵阶数不匹配.
  • LMMC_STATUS_SINGULAR_MATRIX - U 对角线为零.
  • LMMC_STATUS_ALLOCATION_FAILED - 临时工作内存分配失败.
副作用
  • 覆写 x->data.分配并释放长度为 n 的临时工作数组.
