lmmc_status_t lmmc_rng_gamma ( lmmc_rng_t * rng,
lmmc_real_t shape,
lmmc_real_t scale,
lmmc_real_t * out )

生成 Gamma 分布样本 \(\mathrm{Gamma}(\alpha, \beta)\) 。

使用 Marsaglia-Tsang 方法（shape >= 1），shape < 1 时使用 \(X = Y \cdot U^{1/\alpha}\) 变换法（Y ~ Gamma(1+α, β)）。

参数
[in]rng已初始化的 RNG。
[in]shape形状参数 \(\alpha\) （> 0）。
[in]scale尺度参数 \(\beta\) （> 0）。
[out]out输出样本值。
返回
LMMC_STATUS_OK 成功； LMMC_STATUS_INVALID_ARGUMENT 若参数非有限、shape <= 0、 scale <= 0 或指针为 NULL。
副作用
  • 就地修改 rng 的内部状态（消耗多个随机数，次数不确定）。
  • 不分配堆内存。

shape < 1 时采用采样恒等式 Gamma(shape) = Gamma(shape+1) * U^(1/shape)。

shape >= 1 时使用 Marsaglia-Tsang 法。

以挤压界快速判定接受。

按完整接受条件判定候选值。

生成 Beta 分布样本 Beta(alpha, beta)。

参数
[in]rng已初始化的 RNG。
[in]alpha参数 alpha（> 0）。
[in]beta_param参数 beta（> 0）。
[out]out[0,1] 内的有限样本，仅成功时写入。 对数 Gamma 比例支持极小形状参数；舍入或下溢可产生端点 0/1。
返回
LMMC_STATUS_OK 表示成功；LMMC_STATUS_INVALID_ARGUMENT 表示空指针 或非有限、非正形状参数，此时 RNG 保持原状态； LMMC_STATUS_NUMERICAL_FAILURE 表示中间数值无效； LMMC_STATUS_CONVERGENCE_FAILED 表示排除均匀随机数零端点的尝试次数耗尽。
注解
采样失败时 RNG 状态可能已推进。
