lmmc_status_t lmmc_sparse_builder_create ( size_t rows,
size_t cols,
size_t initial_capacity,
lmmc_sparse_builder_t ** out_builder )

创建稀疏矩阵增量构造器.

适用于非零元个数未知或乱序插入的场景.构造器内部维护动态数组, 容量不足时自动翻倍扩容.最终调用 lmmc_sparse_builder_build 生成 压缩格式矩阵.

参数
[in]rows矩阵行数,必须 > 0.
[in]cols矩阵列数,必须 > 0.
[in]initial_capacity初始预分配条目数;0 时使用内部默认值 16.
[out]out_builder返回的构造器句柄指针.
返回
  • LMMC_STATUS_OK - 成功.
  • LMMC_STATUS_INVALID_ARGUMENT - rows/cols 为 0 或 out_builder 为 NULL.
  • LMMC_STATUS_ALLOCATION_FAILED - 内存分配失败.
副作用
  • 分配堆内存.调用方必须配对调用 lmmc_sparse_builder_destroy 释放.

lmmc_status_t lmmc_sparse_builder_add ( lmmc_sparse_builder_t * builder,
size_t row,
size_t col,
lmmc_real_t value )

向构造器追加一项非零元.

若 (row, col) 已存在,数值会在 build 时被累加合并. 容量不足时自动翻倍扩容.

参数
[in,out]builder构造器句柄.
[in]row行下标,必须 < rows.
[in]col列下标,必须 < cols.
[in]value非零元数值.
返回
  • LMMC_STATUS_OK - 成功.
  • LMMC_STATUS_INVALID_ARGUMENT - builder 为 NULL 或下标越界.
  • LMMC_STATUS_ALLOCATION_FAILED - 扩容时内存分配失败.
副作用
  • 修改构造器内部状态(nnz 递增,可能触发 realloc).

◆ lmmc_sparse_builder_build()

lmmc_status_t lmmc_sparse_builder_build ( lmmc_sparse_builder_t * builder,
lmmc_sparse_format_t format,
lmmc_sparse_mat_t * out_sparse )

将构造器中的条目转换为指定格式的稀疏矩阵.

重复 (row,col) 条目的数值会被累加合并.转换后构造器仍有效, 可继续追加条目或再次 build.

参数
[in]builder构造器句柄.
[in]format目标格式(CSR 或 CSC).
[out]out_sparse输出稀疏矩阵,调用方需配对调用 lmmc_sparse_destroy 释放.
返回
  • LMMC_STATUS_OK - 成功.
  • LMMC_STATUS_INVALID_ARGUMENT - 参数为 NULL.
  • LMMC_STATUS_ALLOCATION_FAILED - 内存分配失败.
副作用
  • 分配堆内存用于 out_sparse 的数组.构造器本身不被修改.
