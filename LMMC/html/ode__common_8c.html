◆ lmmc_ode_default_config()

lmmc_status_t lmmc_ode_default_config ( lmmc_real_t t_start,
lmmc_real_t t_end,
size_t problem_dim,
lmmc_ode_config_t * out_cfg )

根据积分区间与维度生成合理的默认求解配置。

根据 t_start 与 t_end 的跨度自动设置初始步长、最小/最大步长、 容差及最大步数等参数，适合大多数非刚性问题。

参数
[in]t_start积分起始时间。
[in]t_end积分终止时间。
[in]problem_dim状态向量维度（>= 1）。
[out]out_cfg输出配置结构体，所有字段将被覆盖写入。
返回
LMMC_STATUS_OK 成功； LMMC_STATUS_INVALID_ARGUMENT 若 problem_dim == 0 或 out_cfg 为 NULL。
副作用
  • 将 out_cfg 指向的结构体全部字段覆盖写入默认值。
  • 不分配堆内存。
