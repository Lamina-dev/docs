详细描述

LMMC 当前线程的初始化与底层栈管理接口.

LMMC 在内部使用 LMMP 的线程局部临时内存.每个调用线程必须独立获取 生命周期租约,并在同一线程中成对释放.

◆ lmmc_deinit()

lmmc_status_t lmmc_deinit ( void )

Release one lifecycle lease owned by the current thread.

A final matching call releases only the current thread's LMMP temporary stack state. Persistent LMMC objects use the recoverable heap bridge and may outlive deinitialization; concurrent mutation still requires external synchronization.

返回
LMMC_STATUS_OK on success or LMMC_STATUS_NOT_INITIALIZED when no lease is active.

◆ lmmc_stack_reset()

lmmc_status_t lmmc_stack_reset ( size_t pool_size)

Reset the current thread's LMMP temporary-stack capacity.

The reset is rejected only while this thread holds nested lifecycle leases. Persistent vectors, matrices, tensors, interpolation objects, and RNG handles do not block a temporary-stack reset.

参数
pool_sizeRequested LMMP temporary-pool size in bytes.
返回
LMMC_STATUS_OK on success, LMMC_STATUS_NOT_INITIALIZED without an active lease, or LMMC_STATUS_BUSY for a nested lease.

long long lmmc_debug_leaks_get_count ( void )

Get the number of persistent allocations currently owned by LMMC.

Available only when compiled with LMMC_DEBUG_LEAKS. The process-wide atomic count follows bridge allocations and remains correct when an object is destroyed on a different thread.
