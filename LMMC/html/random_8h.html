详细描述

伪随机数发生器与常用分布。

内部使用线程不安全的 PCG/xoshiro 类生成器（不透明实现）， 调用方应为每个线程独立创建 lmmc_rng_t 。

◆ lmmc_rng_create()

lmmc_status_t lmmc_rng_create ( lmmc_rng_t ** out_rng)

创建随机数发生器实例。

分配并初始化一个 xoshiro256** 发生器。句柄由调用方拥有，默认 线程受限；跨线程传递或并发访问必须由调用方同步。并行工作负载应为 每个线程创建独立句柄，或使用 lmmc_rng_clone 和 ::lmmc_rng_jump。

参数
[out]out_rng输出新创建的 RNG 句柄。
返回
LMMC_STATUS_OK 成功； LMMC_STATUS_INVALID_ARGUMENT 若 out_rng 为 NULL； LMMC_STATUS_ALLOCATION_FAILED 若内存分配失败。
副作用
  • 分配堆内存存储 RNG 内部状态，调用方必须调用 lmmc_rng_destroy 释放。

将平台熵混入默认种子,为各随机数发生器建立独立数据流.

lmmc_status_t lmmc_rng_uniform ( lmmc_rng_t * rng,
lmmc_real_t a,
lmmc_real_t b,

实数分布参数的公共约束。

所有实数参数必须有限；尺度、形状、速率和自由度参数还必须为正数。 违反约束时返回 LMMC_STATUS_INVALID_ARGUMENT，且不会进入拒绝采样循环。

在 \([a,b)\) 区间内生成均匀分布样本。

使用防溢出的仿射插值；有限端点即使跨越完整 double 范围也不会因 计算 b-a 而产生无穷值。

◆ lmmc_rng_gamma()

lmmc_status_t lmmc_rng_gamma ( lmmc_rng_t * rng,
lmmc_real_t shape,
lmmc_real_t scale,
lmmc_real_t * out )

生成 Gamma 分布样本 \(\mathrm{Gamma}(\alpha, \beta)\) 。

使用 Marsaglia-Tsang 方法（shape >= 1），shape < 1 时使用 \(X = Y \cdot U^{1/\alpha}\) 变换法（Y ~ Gamma(1+α, β)）。

参数
[in]rng已初始化的 RNG。
[in]shape形状参数 \(\alpha\) （> 0）。
[in]scale尺度参数 \(\beta\) （> 0）。
[out]out输出样本值。
返回
LMMC_STATUS_OK 成功； LMMC_STATUS_INVALID_ARGUMENT 若参数非有限、shape <= 0、 scale <= 0 或指针为 NULL。
副作用
  • 就地修改 rng 的内部状态（消耗多个随机数，次数不确定）。
  • 不分配堆内存。

shape < 1 时采用采样恒等式 Gamma(shape) = Gamma(shape+1) * U^(1/shape)。

shape >= 1 时使用 Marsaglia-Tsang 法。

以挤压界快速判定接受。

按完整接受条件判定候选值。

lmmc_real_t lambda,

生成 Poisson 分布样本 \(\mathrm{Poisson}(\lambda)\) 。

lambda >= 10 使用 PTRD（Hörmann）算法（接受-拒绝）， lambda < 10 使用逆变换法（Knuth 方法）。

参数
[in]rng已初始化的 RNG。
[in]lambda期望值（> 0）。
[out]out输出样本值（非负整数）。
返回
LMMC_STATUS_OK 成功； LMMC_STATUS_INVALID_ARGUMENT 若 lambda 非有限、<= 0 或指针为 NULL； LMMC_STATUS_NUMERICAL_FAILURE 若样本超出 size_t 范围或中间量非有限。
注解
不分配堆内存；接受-拒绝过程消耗的随机数次数不固定。 out 仅成功时写入，失败时 RNG 状态可能已推进。
