◆ lmmc_mat_create()

lmmc_status_t lmmc_mat_create ( size_t rows,
size_t cols,
lmmc_mat_t * out_mat )

创建 rows x cols 的零矩阵。

用 lmmc_alloc 分配 rows*cols 个 lmmc_real_t 的连续缓冲区， stride=cols，owns_data=1。

参数
[in]rows行数，须 > 0。
[in]cols列数，须 > 0。
[out]out_mat调用方提供的矩阵结构体，全部字段被覆写。
返回
  • LMMC_STATUS_OK - 成功。
  • LMMC_STATUS_INVALID_ARGUMENT - rows 或 cols 为 0、out_mat 为 NULL 或 rows*cols 溢出。
  • LMMC_STATUS_ALLOCATION_FAILED - 内存分配失败。
注解
调用方须用 lmmc_mat_destroy 释放缓冲区。
函数无共享状态；lmmc_alloc 线程安全时支持并发调用。

◆ lmmc_mat_wrap()

lmmc_status_t lmmc_mat_wrap ( size_t rows,
size_t cols,
size_t stride,
lmmc_real_t * data,
lmmc_mat_t * out_mat )

创建引用调用方连续缓冲区的矩阵视图。

所有权保留给调用方，data 的生命周期须覆盖视图使用期。 lmmc_mat_destroy 仅销毁视图，写入视图会直接修改 data。

参数
[in]rows行数，须 > 0。
[in]cols列数，须 > 0。
[in]stride相邻行首元素间距，须 >= cols。
[in]data非 NULL 的外部缓冲区，至少容纳 rows*stride 个 lmmc_real_t。
[out]out_mat输出矩阵视图，全部字段被覆写。
返回
  • LMMC_STATUS_OK - 成功。
  • LMMC_STATUS_INVALID_ARGUMENT - 参数非法。
注解
直接使用外部缓冲区，无内存分配。

◆ lmmc_mat_destroy()

void lmmc_mat_destroy ( lmmc_mat_t * mat)

销毁矩阵，释放其拥有的缓冲区并清零结构体字段。

owns_data 非零时用 lmmc_free 释放 data；外部缓冲区保留。 销毁后 data 为 NULL，rows、cols、stride 为零；重新 create/wrap 后可用于运算。

参数
[in,out]mat待销毁矩阵，接受 NULL 或已销毁（data==NULL）的矩阵。
