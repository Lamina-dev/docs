◆ lmmc_lgamma()

lmmc_status_t lmmc_lgamma ( lmmc_real_t x,
lmmc_real_t * out )

使用 Lanczos 近似计算对数伽马函数（g=7，n=9）。

计算对数伽马函数 \(\ln\Gamma(x)\) ,要求 \(x > 0\) .

ln(Gamma(x)) = (x - 0.5) * ln(x + g - 0.5) - (x + g - 0.5) + 0.5*ln(2*pi) + ln(Ag(x))， 其中 Ag(x) 为 Lanczos 级数和。

使用 Lanczos 近似计算对数伽马函数（g=7，n=9）。

使用 Lanczos 近似(g=7, n=9 系数),精度约 15 位有效数字.

参数
[in]x输入值,必须为正数.
[out]out输出 \(\ln\Gamma(x)\) .
返回
LMMC_STATUS_OK 成功; LMMC_STATUS_INVALID_ARGUMENT 若 x <= 0 或 out 为 NULL.
注解
不分配内存，输入保持原值。

Numerical Recipes / Cephes 的 Lanczos 系数（g=7，n=9）。

反射公式：Gamma(x) * Gamma(1-x) = pi / sin(pi*x)。

对数形式：lgamma(x) = ln(pi) - ln(sin(pi*x)) - lgamma(1-x)。

◆ lmmc_digamma()

lmmc_status_t lmmc_digamma ( lmmc_real_t x,
lmmc_real_t * out )

计算双伽马函数 psi(x) = d/dx ln(Gamma(x))。

计算双伽马函数 \(\psi(x) = \frac{d}{dx}\ln\Gamma(x)\) ,要求 \(x > 0\) .

按 psi(x+1) = psi(x) + 1/x 递推至 x >= 7，再使用渐近展开： psi(x) ~ ln(x) - 1/(2x) - sum_{k=1}^{N} B_{2k}/(2k * x^{2k})， 其中 B_{2k} 为 Bernoulli 数。

计算双伽马函数 psi(x) = d/dx ln(Gamma(x))。

使用递推关系将 x 提升到大值区域后应用渐近展开.

参数
[in]x输入值,必须为正数.
[out]out输出 \(\psi(x)\) .
返回
LMMC_STATUS_OK 成功;LMMC_STATUS_INVALID_ARGUMENT 若 x <= 0 或 out 为 NULL.

渐近展开：psi(x) ~ ln(x) - 1/(2x) - 1/(12x^2) + 1/(120x^4) - 1/(252x^6) + ...。

Bernoulli 数：B2=1/6，B4=-1/30，B6=1/42，B8=-1/30，B10=5/66，B12=-691/2730。

展开系数为 B_{2k} / (2k)。

< 系数：B2/(2*1) = (1/6)/2。

< 系数：B4/(2*2) = (-1/30)/4。

< 系数：B6/(2*3) = (1/42)/6。

< 系数：B8/(2*4) = (-1/30)/8。

< 系数：B10/(2*5) = (5/66)/10。

< 系数：B12/(2*6) = (-691/2730)/12。

< 系数：B14/(2*7) = (7/6)/14 = 1/12。

< ix^(2k)，初值为 ix^2。

◆ lmmc_lambertw()

lmmc_status_t lmmc_lambertw ( lmmc_real_t z,
lmmc_real_t * out_res )

计算 Lambert W 函数主分支 \(W_0(z)\) .

微小输入使用逆级数，分支点附近使用抗消减级数，其余使用带保护的 Halley/二分迭代求解单调残差。恰等于 -LMMC_INV_E 的 binary64 输入 代表端点 -1/e，返回 -1；相邻输入按各自值处理。W0 保留零的符号。

前向误差工程目标为 64*DBL_EPSILON*abs(W)+2*minimum_subnormal。 验收以残差误差半径包围根，计入 binary64 舍入，并假设所支持 libm 的 log/exp/expm1 误差至多为 2 ULP；此为工程误差模型， 不构成精确算术证明或 C 标准对 libm 的保证。

参数
[in]z大于或等于端点代表值的有限输入。
[out]out_res有限结果，仅在成功时写入。
返回
OK 表示成功；INVALID_ARGUMENT 表示有限输入超出定义域或输出为空； NUMERICAL_FAILURE 表示输入或中间量非有限； CONVERGENCE_FAILED 表示 100 次迭代仍无法确认前向误差目标。
