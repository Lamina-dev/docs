lmmc_status_t lmmc_sparse_create_csr ( size_t rows,
size_t cols,
size_t nnz,
lmmc_sparse_mat_t * out_sparse )

为指定 nnz 的 CSR 矩阵分配数组。

owns_data=1，row_ptr 清零，col_idx/values 未初始化。 调用方须填充三个数组，满足 sparse_types.h 中索引严格有序、 坐标唯一的压缩结构契约后使用。

参数
[in]rows行数，须 > 0。
[in]cols列数，须 > 0。
[in]nnz非零元个数，可为 0。
[out]out_sparse输出矩阵，调用方须用 lmmc_sparse_destroy 释放。
返回
  • LMMC_STATUS_OK - 成功。
  • LMMC_STATUS_INVALID_ARGUMENT - rows/cols 为 0 或 out_sparse 为 NULL。
  • LMMC_STATUS_ALLOCATION_FAILED - 内存分配失败。

◆ lmmc_sparse_wrap_csr()

lmmc_status_t lmmc_sparse_wrap_csr ( size_t rows,
size_t cols,
size_t nnz,
size_t * row_ptr,
size_t * col_idx,
lmmc_real_t * values,
lmmc_sparse_mat_t * out_sparse )

将调用方缓冲区包装为 CSR 视图。

校验行指针边界、单调性及每行索引范围和严格递增性，拒绝重复或乱序。 输入及其顺序保持不变，失败时 out_sparse 保持不变。 所有权保留给调用方，::lmmc_sparse_destroy 仅销毁视图。 乱序或重复输入应使用 builder/COO。

参数
[in]rows行数。
[in]cols列数。
[in]nnz非零元个数。
[in]row_ptr行指针数组，长度 rows+1，row_ptr[0]==0，row_ptr[rows]==nnz。
[in]col_idx列索引数组，长度 nnz，每行严格递增且各值 < cols。
[in]values数值数组，长度 nnz。
[out]out_sparse输出矩阵视图。
返回
  • LMMC_STATUS_OK - 成功。
  • LMMC_STATUS_INVALID_ARGUMENT - 参数非法或结构校验失败。
注解
无内存分配，写入视图会直接修改外部缓冲区。

◆ lmmc_sparse_destroy()

void lmmc_sparse_destroy ( lmmc_sparse_mat_t * sparse)

销毁稀疏矩阵，释放其拥有的缓冲区并清零全部字段。

owns_data 非零时释放 row_ptr、col_idx、values；外部缓冲区保留。 销毁后矩阵须重新初始化才能用于运算。

参数
[in,out]sparse待销毁矩阵，接受 NULL。
