◆ lmmc_mat_norm_fro()

lmmc_status_t lmmc_mat_norm_fro ( const lmmc_mat_t * a,
lmmc_real_t * out_norm )

计算矩阵的 Frobenius 范数: \(\|A\|_F = \sqrt{\sum_{i,j} A_{ij}^2}\)。

采用缩放平方和累加；最终结果超出 binary64 范围时可为无穷。

参数
[in]a输入矩阵(不被修改)。
[out]out_norm输出范数值。
返回
  • LMMC_STATUS_OK - 成功。
  • LMMC_STATUS_INVALID_ARGUMENT - 指针为 NULL。
