◆ lmmc_tensor_nd_create()

lmmc_status_t lmmc_tensor_nd_create ( size_t ndim,
const size_t * dims,
lmmc_tensor_nd_t * out )

创建 N-D 张量,行优先连续存储,元素初始化为零.

分配 dims[0] x dims[1] x ... x dims[ndim-1] 个元素的连续缓冲区, 并设置行优先步距.输出张量的 owns_data 为 1.

参数
[in]ndim维度数,范围 [1, LMMC_TENSOR_MAX_NDIM].
[in]dims各维大小数组,长度 ndim ,每个元素须 >= 1;可指向 out->dims.
[out]out输出张量结构体(调用方提供存储).
返回
LMMC_STATUS_OK 成功; LMMC_STATUS_INVALID_ARGUMENT 若 ndim 超出范围,dims 含零,元素数或字节数溢出,或指针为 NULL; LMMC_STATUS_ALLOCATION_FAILED 若内存分配失败.
注解
覆写 out 的全部字段；堆分配的数据缓冲区由调用方 调用 lmmc_tensor_nd_destroy 释放。
