lmmc_status_t lmmc_sparse_builder_create ( size_t rows,
size_t cols,
size_t initial_capacity,

创建稀疏矩阵增量构造器。

支持未知条目数和乱序插入，动态数组容量不足时翻倍扩容。 用 lmmc_sparse_builder_build 生成压缩格式矩阵。

参数
[in]rows矩阵行数，须 > 0。
[in]cols矩阵列数，须 > 0。
[in]initial_capacity初始容量，0 时采用默认值 16。
[out]out_builder输出构造器句柄。
返回
  • LMMC_STATUS_OK - 成功。
  • LMMC_STATUS_INVALID_ARGUMENT - rows/cols 为 0 或 out_builder 为 NULL。
  • LMMC_STATUS_ALLOCATION_FAILED - 内存分配失败。
注解
分配堆内存，调用方须用 lmmc_sparse_builder_destroy 释放。

将构造器条目转换为指定压缩格式的稀疏矩阵。

[out]out_sparse输出稀疏矩阵，调用方须用 lmmc_sparse_destroy 释放。
返回
  • LMMC_STATUS_OK - 成功。
  • LMMC_STATUS_INVALID_ARGUMENT - 参数为 NULL 或 format 非 CSR/CSC。
  • LMMC_STATUS_ALLOCATION_FAILED - 内存分配失败。
注解

◆ lmmc_sparse_wrap_csr()

lmmc_status_t lmmc_sparse_wrap_csr ( size_t rows,
size_t cols,
size_t nnz,
size_t * row_ptr,
size_t * col_idx,
lmmc_real_t * values,
lmmc_sparse_mat_t * out_sparse )

将调用方缓冲区包装为 CSR 视图。

校验行指针边界、单调性及每行索引范围和严格递增性，拒绝重复或乱序。 输入及其顺序保持不变，失败时 out_sparse 保持不变。 所有权保留给调用方，::lmmc_sparse_destroy 仅销毁视图。 乱序或重复输入应使用 builder/COO。

参数
[in]rows行数。
[in]cols列数。
[in]nnz非零元个数。
[in]row_ptr行指针数组，长度 rows+1，row_ptr[0]==0，row_ptr[rows]==nnz。
[in]col_idx列索引数组，长度 nnz，每行严格递增且各值 < cols。
[in]values数值数组，长度 nnz。
[out]out_sparse输出矩阵视图。
返回
  • LMMC_STATUS_OK - 成功。
  • LMMC_STATUS_INVALID_ARGUMENT - 参数非法或结构校验失败。
注解
无内存分配，写入视图会直接修改外部缓冲区。
