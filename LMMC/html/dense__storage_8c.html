◆ lmmc_mat_create()

lmmc_status_t lmmc_mat_create ( size_t rows,
size_t cols,
lmmc_mat_t * out_mat )

分配并初始化一个 rows x cols 的稠密矩阵,所有元素置零.

内部通过 lmmc_alloc 分配 rows*cols 个 lmmc_real_t 的连续缓冲区, stride 设为 cols(紧凑存储),owns_data 置 1.

参数
[in]rows行数,必须 > 0.
[in]cols列数,必须 > 0.
[out]out_mat输出矩阵结构体(调用方提供栈/堆上的结构体地址).
返回
  • LMMC_STATUS_OK - 成功.
  • LMMC_STATUS_INVALID_ARGUMENT - rows 或 cols 为 0,或 out_mat 为 NULL,或 rows*cols 溢出.
  • LMMC_STATUS_ALLOCATION_FAILED - 内存分配失败.
副作用
  • 分配堆内存(通过 lmmc_alloc),调用方必须配对调用 lmmc_mat_destroy 释放.
  • out_mat 的所有字段被覆写.
线程安全
本函数本身无共享状态,多线程可并发调用(前提是 lmmc_alloc 线程安全).

◆ lmmc_mat_wrap()

lmmc_status_t lmmc_mat_wrap ( size_t rows,
size_t cols,
size_t stride,
lmmc_real_t * data,
lmmc_mat_t * out_mat )

创建引用调用方连续缓冲区的矩阵视图.

将已有的连续内存区域包装为 lmmc_mat_t,并将缓冲区所有权保留给调用方. lmmc_mat_destroy 仅销毁视图;调用方负责让 data 的生命周期覆盖视图使用期.

参数
[in]rows行数,必须 > 0.
[in]cols列数,必须 > 0.
[in]stride行步距(相邻行首元素间距),要求 >= cols .
[in]data外部缓冲区指针,至少容纳 rows*stride 个 lmmc_real_t.不可为 NULL.
[out]out_mat输出矩阵视图.
返回
  • LMMC_STATUS_OK - 成功.
  • LMMC_STATUS_INVALID_ARGUMENT - 参数非法.
副作用
  • 无内存分配.out_mat 的所有字段被覆写.
  • 对视图的写操作会直接修改 data 指向的外部缓冲区.

◆ lmmc_mat_destroy()

void lmmc_mat_destroy ( lmmc_mat_t * mat)

销毁矩阵,释放其拥有的底层缓冲区.

若 mat->owns_data 非零,调用 lmmc_free 释放 mat->data; 否则仅将结构体字段清零.对 NULL 指针或已销毁(data==NULL)的矩阵安全.

参数
[in,out]mat待销毁的矩阵,可为 NULL.
副作用
  • 若 owns_data:释放堆内存,mat->data 置 NULL,rows/cols/stride 清零.
  • 若 !owns_data:仅清零结构体字段,不释放外部缓冲区.
  • 销毁后该矩阵不可再用于任何运算(除非重新 create/wrap).

  • LMMC_STATUS_INVALID_ARGUMENT - 任一指针或 data 为 NULL.
  • LMMC_STATUS_DIMENSION_MISMATCH - src 与 dst 维度不同.
副作用
  • 覆写 dst->data 中的全部元素.src 不被修改.

lmmc_status_t lmmc_mat_transpose_to ( const lmmc_mat_t * src,
lmmc_mat_t * dst )

计算矩阵转置:dst = src^T.

dst 的维度必须为 (src->cols x src->rows)，且其半开存储包络不得与 src 重叠。

参数
[in]src源矩阵 (mxn).
[out]dst目标矩阵,必须已创建为 (nxm).
返回
  • LMMC_STATUS_OK - 成功.
  • LMMC_STATUS_INVALID_ARGUMENT - 指针为 NULL、存储包络溢出或 src/dst 重叠.
  • LMMC_STATUS_DIMENSION_MISMATCH - dst 维度与 (src->cols x src->rows) 不匹配（优先于重叠检查）.
副作用
  • 覆写 dst->data.src 不被修改.无内存分配.
