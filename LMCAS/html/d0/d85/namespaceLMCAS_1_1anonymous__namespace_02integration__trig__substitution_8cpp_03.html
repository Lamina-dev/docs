base 必须是 c0 + c2*x²（关于 var 的二次、无一次项）

提取关于 var 的系数：c0（常数）、c1（一次）、c2（二次） 用求导法：c2 = (1/2) d²/dx² ; c1 = d/dx |_{x=0} ; c0 = base|_{x=0}

必须 c1=0，且 c2 为非零常数，c0 常数，且 d2 不依赖 var（纯二次）

仅支持 c2 = ±1（标准型 a²±x² / x²-a²）
