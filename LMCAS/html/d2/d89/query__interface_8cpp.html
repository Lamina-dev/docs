详细描述

Implementation of the QueryInterface class.

The QueryInterface is the single public entry point for property queries. It handles special cases (null, NaN, Infinity, Matrix, Relational, Logical) and delegates to the InferenceEngine for all other node types.

Query results are cached by (expression_hash, property_type) to avoid redundant inference. The cache is invalidated on any AssumptionContext mutation.
