5 * 本模块处理同时包含超越函数(sin,cos,tan,exp,ln)和代数项的方程.

115/**
116 * @brief 自适应根隔离:将搜索区间划分为含至多一个根的子区间.
117 *
118 * 通过递归二分检测符号变化,定位根所在子区间.当导数可用时,
119 * 利用导数符号确认子区间内的单调性(即恰含一个根).
120 *
121 * 特殊处理:
122 * - 子区间宽度 < 1e-6 时停止细分;
123 * - 采样点产生 NaN/Inf 时跳过并缩小区间重新采样;
124 * - 超过 max_roots 限制时截断返回.
125 *
126 * @param[in] expr 表达式
127 * @param[in] derivative 表达式的导数(可为 nullptr,跳过单调性确认)
128 * @param[in] var 变量名
129 * @param[in] interval 搜索区间
130 * @param[in] opts 求解选项(max_roots,tolerance)
131 * @return 隔离子区间列表
132 */
133LAMINA_API std::vector<IsolatedInterval> isolate_roots(
134 const std::shared_ptr<SymbolicExpr>& expr,
135 const std::shared_ptr<SymbolicExpr>& derivative,
