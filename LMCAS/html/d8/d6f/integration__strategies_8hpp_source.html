128/**
129 * @brief 三角组合积分策略:处理 sin^m(x)*cos^n(x),tan^n(x),sec^n(x) 形式.
130 *
131 * 当被积函数形如:
132 * - sin^m(var)*cos^n(var)(m,n 为非负整数,m+n <= 8),或
133 * - tan^n(var)(n 为整数,2 <= n <= 8),或
134 * - sec^n(var)(n 为偶数,2 <= n <= 8)
135 * 时,使用 Pythagorean 恒等式与降幂公式得到闭式原函数:
136 * - 奇数次幂情形(m 或 n 为奇数)通过 u = cos(x) 或 u = sin(x) 换元求解;
137 * - 双偶数情形(m,n 均为偶数)通过半角恒等式 sin^2 = (1-cos2x)/2 / cos^2 = (1+cos2x)/2 递归降阶;
138 * - tan^n 通过 tan^n = tan^(n-2)*(sec^2-1) 递归化简;
139 * - 偶数 sec^n 通过分部积分得到的递推公式化简.
140 *
141 * sin/cos/tan/sec 的内部参数必须恰为积分变量本身(如 sin(2x) 由 LinearSubstitutionStrategy 处理).
142 * 若指数为非整数,负数或超出 m+n > 8 的总度数限制,则返回 nullptr 让链上后续策略尝试.
143 */

229/**
230 * @brief 高次有理函数部分分式积分策略:处理分母次数 >= 3 的有理函数 P(x)/Q(x).
231 *
232 * 工作流程:
233 * 1. extract_rational:将被积表达式分解为 P(x)/Q(x),要求 P,Q 均为关于积分变量
234 * 的多项式,系数为有理数;非有理形式时返回 false.
235 * 2. poly_divide:当 deg(P) >= deg(Q) 时进行多项式长除法,得到商和余式;商部分用幂律
236 * 逐项积分,剩余的真分式进入部分分式分解.
237 * 3. factor_denominator:用 square_free_factorization 加上有理根定理,把 Q 分解为
238 * 线性因子和有理域上的二次整体因子;高次整体因子使分解阶段返回 false.
239 * 4. solve_coefficients:对每个因子按重数引入待定系数(线性因子贡献 A_l/(x-r)^l,
240 * 二次因子贡献 (B_l*x + C_l)/q(x)^l),通过比较多项式系数列出线性方程组,使用
241 * gaussian_eliminate 求解.
242 * 5. integrate_term:逐项积分:
243 * - A/(x-r)^l:l=1 生成 ln|x-r|,l>1 生成幂函数;
244 * - (Bx+C)/q(x):分裂为 ln 和 arctan 两部分(完全平方);
245 * - q^l(l>=2)映射为保留原语义的未求值积分节点.
246 *
247 * 支持域映射:
248 * - 零分母,因式分解未决与线性系统未决映射为未求值积分节点;
249 * - 其他表达式返回 nullptr,由策略链继续匹配.
250 */
