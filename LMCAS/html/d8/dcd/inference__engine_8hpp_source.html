30/**
31 * @brief Derives properties of composite expressions by recursively analyzing sub-expressions.
32 *
33 * The InferenceEngine implements arithmetic inference rules for addition, multiplication,
34 * power, and function expressions. It determines sign, domain, and boundedness properties
35 * based on the properties of operands/arguments.
36 *
37 * Sign inference rules:
38 * - Addition: uniform sign → same sign on sum; mixed/unknown → Unknown
39 * - Multiplication: zero → Zero; parity of negatives determines sign; unknown → Unknown
40 * - Power: positive base + real exponent → Positive; even exponent → NonNegative; etc.
41 * - Functions: exp → Positive; abs → NonNegative; sin/cos → Bounded[-1,1]; etc.
42 *
43 * Domain inference rules:
44 * - Addition: all Integer → Integer; all Real → Real
45 * - Multiplication: all Integer → Integer; all Real/Integer → Real
46 * - Power: Real base + integer exponent → Real
47 * - Functions: exp/sin/cos/abs/sqrt/ln/tan with Real argument → Real
48 */

186 * Auto-infers monotonicity for known functions:

209 * @brief Apply monotonicity deduction rules when a new relation is added.
