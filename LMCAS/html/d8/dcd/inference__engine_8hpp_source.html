38/**
39 * @brief Derives properties of composite expressions by recursively analyzing sub-expressions.
40 *
41 * The InferenceEngine implements arithmetic inference rules for addition, multiplication,
42 * power, and function expressions. It determines sign, domain, and boundedness properties
43 * based on the properties of operands/arguments.
44 *
45 * Sign inference rules:
46 * - Addition: uniform sign -> same sign on sum; mixed/unknown -> Unknown
47 * - Multiplication: zero -> Zero; parity of negatives determines sign; unknown -> Unknown
48 * - Power: positive base + real exponent -> Positive; even exponent -> NonNegative; etc.
49 * - Functions: exp -> Positive; abs -> NonNegative; sin/cos -> Bounded[-1,1]; etc.
50 *
51 * Domain inference rules:
52 * - Addition: all Integer -> Integer; all Real -> Real
53 * - Multiplication: all Integer -> Integer; all Real/Integer -> Real
54 * - Power: Real base + integer exponent -> Real
55 * - Functions: exp/sin/cos/abs/sqrt/ln/tan with Real argument -> Real
56 *
57 * @par Thread safety
58 * An instance is thread-confined. Concurrent calls on the same instance are
59 * unsupported because recursion guards and active-query state are mutable.
60 * Separate instances bound to immutable contexts may be used concurrently.
61 * A quiescent instance may be moved to another thread before its next call.
62 */
