27 B 基数，已被硬编码为 2^64

29 [p,n,b] 表示指针p指向的、以b为基数的n位数
30 p[i-1] 代表其第i位最低有效位 (0<i<=n)
31 如果省略b，则默认基数为B。通常情况下，
32 用此符号表示函数参数时，一般暗指高位不存在0，
33 在不太严格场景中，比如乘法和加减法中，即使存在高位0
34 通常也不会导致错误，在严格的除法或者其他运算中，会强调
35 高位不能是0。
36 用此符号表示函数返回值时，也表示将会写入的区间，
37 即使可能写入为0。
38
39 sep 指针指向的内存区域完全分离
40
41 eqsep 完全相同的内存区域或者完全分离
42
43 备注：我们都假定地址是向上增长的，dst <= num+1
44 的内存布局可以这样表示
45 dst ──┐
46 num ──┐ |00000000|00000000|
47 |********|********|
48
49 MSB(x) x的最高有效位，比如最高有效位为1，MSB(x)=1
50 代表 x >= B / 2
51
52 [x|y] x或y，用于表示参数或返回值的取值范围
53

216/*
217 LAMMP 内存分配函数指针类型：
218 1. heap_alloc : 堆内存分配器
219 2. heap_free : 堆内存释放器
220 3. realloc : 堆内存重新分配器
221
222 默认使用 malloc、free、realloc 实现。
223 如果你需要传入自定义的分配器，为了避免重复处理，且由于LAMMP内部几乎不直接
224 通过指定的指针来进行内存分配，所以为了避免不必要的错误处理，建议遵循一下的行为：
225 1. 传给free的指针应可以为NULL
226 2. malloc(size)可以假定size>0，若size为0，可以是未定义行为，可以直接中断。
227 3. realloc(p, size)可以假定size>0，若size为0，可以是未定义行为，可以直接中断。
228 4. realloc/malloc(p, size)若内存耗尽，或者无空闲块，可以返回NULL，代表分配失败。
229 */
230
231typedef void* (*lmmp_heap_alloc_fn)(size_t size);
232typedef void (*lmmp_heap_free_fn )(void* ptr);
233typedef void* (*lmmp_realloc_fn )(void* ptr, size_t size);
234
235typedef struct {
236 lmmp_heap_alloc_fn alloc;
237 lmmp_heap_free_fn free;
238 lmmp_realloc_fn realloc;
239} lmmp_heap_allocator_t;

241/**
242 * @brief 设置 LAMMP 全局堆内存分配函数
243 * @param heap 新的堆内存分配器，可以为NULL，此时会直接返回，而不进行任何操作。
244 * @warning 由于所有共享内存都采用堆内存分配。因此，传入新的堆分配器将会首先调用
245 * lmmp_global_deinit 函数，释放所有共享内存，以保证老旧的堆资源被释放。
246 * 然后将会自动调用 lmmp_global_init 函数，重新分配所有线程局部内存。
247 * 同时，为保证内存不泄露，将会对堆计数器和栈顶以及缓冲池顶进行检查。
248 * 若此时堆栈分配计数器不为 0，或当前栈帧不在栈底，都会触发lmmp_abort函数，
249 * 并输出相应的错误信息。
250 * @note 堆分配器是线程局部的，因此，创建新线程时，如有需要，请自行设置新的堆分配器。
251 * 同时也请自行保证分配器和释放器相匹配。
252 */
253LAMMP_API void lmmp_set_heap_allocator(const lmmp_heap_allocator_t* heap);

265/**
266 * @brief LAMMP 全局栈初始化函数（通常不需要手动调用）
267 * @note 初始化默认栈，并分配大小为size的额外内存池。如果已经初始化，
268 * 则会直接返回-1，表示已经初始化（并非错误），且不进行任何其他操作。
269 * lmmp_global_init 函数会自动调用此函数，分配的额外缓冲池大小为 LAMMP_POOL_SIZE 的大小
270 * （默认为512kb），无需手动调用。
271 * 如果你想手动设置缓冲池的大小，可以先调用 lmmp_stack_deinit 函数，再调用此函数，将 POOL_SIZE
272 * 设置为你想要的值。同时你也可以禁用缓冲池（即size为0），此时不会分配额外缓冲池。
273 * @return 返回0表示成功初始化，返回-1表示已经初始化（并非错误）。

308/**
309 * @brief LAMMP 全局退出函数，内部错误或断言失败时调用，若设置了全局退出函数，则会调用该函数，否则会调用默认的退出函数。
310 * @param msg 退出信息，assert类型的错误信息通常仅包含断言内容，其他类型的错误则因类型不同而不同。
311 * @param func 退出处的函数名
312 * @param line 退出处的行号
313 * @param type 退出类型。有以下几个类型：
314 *
315 * 1. ASSERT_FAILURE （枚举值为1）为lmmp_assert触发的退出，lmmp_assert触发的普通退出几乎不可能发生，
316 * 其通常代表不可能发生的计算错误，可能表明程序执行此处时必须正确的输入错误。比如预期无进位的加法产生了进位。
317 * 此类错误不可接受，会导致计算无法继续进行，导致程序崩溃。
318 *
319 * 2. DEBUG_ASSERT_FAILURE （枚举值为2）为lmmp_debug_assert触发的退出。其通常表明预期之外的错误，
320 * 这通常是调用者的UB，如无UB的情况下触发此错误；也可能是LAMMP内部的逻辑错误，开发者期待的输入错误，
321 * 在该逻辑处仅简单考虑了某些情况。如有此类错误，可以报告给开发者。此类型只会在定义了
322 * LAMMP_DEBUG_ASSERT_CHECK 宏为 1 的情况下才会触发。
323 *
324 * 3. PARAM_ASSERT_FAILURE （枚举值为3）为参数检查失败导致的退出。其通常表明调用者传入了无效的参数，
325 * 导致函数的行为不符合预期。此类错误不可接受，会导致计算无法继续进行，导致程序崩溃。此类型的错误只有在
326 * 定义了 LAMMP_DEBUG_PARAM_ASSERT_CHECK 宏为 1 的情况下才会触发。
327 *
328 * 4. MEMORY_ALLOC_FAILURE （枚举值为4）为内存分配失败退出。在使用堆分配器时，申请内存失败，导致触发此错误。
329 * 此类型错误不受明确的宏调控，Realse模式下，会保留必要的触发场景，部分场景下，在一些检查宏定义时，可能会额外触发此错误。
330 *
331 * 5. MEMORY_FREE_FAILURE （枚举值为5）为内存释放错误。当释放堆内存时可能触发，原因通常为头部信息被损坏，极有可能
332 * 源于传入错误的指针，又或者缓冲区溢出导致此头部损坏。LAMMP_DEBUG_MEMORY_CHECK 宏为 1 时，才可能触发。
333 *
334 * 6. OUT_OF_BOUNDS （枚举值为6）为数组越界访问导致的退出。通常表明未按规定使用空间。此类型的错误在堆分配器中，当释放
335 * 堆内存时，检测到数组尾部魔数不匹配，导致此错误。LAMMP_DEBUG_MEMORY_CHECK 宏为 1 时，才可能触发。
336 *
337 * 7. MEMORY_LEAK （枚举值为7）为内存泄漏导致的退出。在检查点处，堆内存计数器不为0，或者当前栈帧不在栈底，又或者缓冲池
338 * 定不在缓冲池底，都会触发此错误。触发原因可能为，在调用堆分配器重置函数时，显式检查到此时的堆计数器不为0或者栈帧
339 * 以及缓冲池不为底部。又或者手动调用 lmmp_leak_tracker 宏来进行检查，检查到了相同的情况。需注意，手动调用此宏时，
340 * 请先调用 lmmp_global_deinit 进行全局共享的堆资源的安全释放（因为部分全局共享资源也会被计数）。
341 *
342 * 8. UNEXPECTED_ERROR （枚举值为8）为其他未知错误导致的退出。
343 *
344 * @warning LAMMP内部中断都将会调用此函数，如果全局退出函数为NULL，则使用默认的退出函数，会打印出全部错误信息，并调用
345 * abort 函数中断程序。自定义全局退出函数请通过 lmmp_set_abort_fn 函数进行设置。请不要在全局退出函数里做任
346 * 何危险的操作，本库的开发者不对其调用产生的影响做任何保证。
347 */
348LAMMP_NORETURN LAMMP_API void lmmp_abort(lmmp_error_t type, const char *msg, const char *func, int line);
