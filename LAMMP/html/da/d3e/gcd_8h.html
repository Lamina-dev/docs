导出另一侧系数：tv = (g - S·X)/Y（S 为 X 侧系数，恒等式保证整除）

参数
dst输出（容量 >= xn+2）
tneg出参，tv 的符号
gpg（归一化）
gng 的长度
spS 的幅度（归一化）
snS 的幅度长
snegS 的符号
xp值序大者原对（归一化）
xn其长度
yp值序小者原对（归一化）
yn其长度
nb全乘积暂存（容量 >= xn+yn+2）
ytY 奇化暂存（容量 >= yn+1）
qt整商暂存（容量 >= xn+2；lmmp_divexact_ 写入长 nn-yn2+1 可超 出 dst 公开容量，先落此处再按归一化长度拷出）
返回
tv 写入长度（tv==0 理论不可达时返回 0）
警告
sep([dst|nb|yt|qt],[gp|sp|xp|yp])，gn>0，sn<=xn
注解
S==0 时 Y|X 且 g==Y，tv=1。Y 偶时剥公因子 2^k 后走 lmmp_divexact_ （要求奇除数；N = tv*Y 保证 N 的低 k 位为零）。S 与 tv 反号（极小 系数性质，|S|*X >= X >= g 使 g 落在 0 与 |S|*X 之间）

注解
峰值沿递归路径取 max 而非逐层求和：递增分配器经 mark 复位使 子层临时空间与本层合并相位（sa/sb 副本、adjust/apply_mod/矩阵 复合缓冲，合计约 14n）共享同一区域，二者不同时达峰；真正叠加 的只有递归期间常驻的高位副本与子矩阵缓冲。子问题规模上界取 2n/3 + 2（阶段 B 的 p2 分裂在最不利时接近该比例，严于实际的 n - n/2 与 2n_cur - n0 - 5）。本层合并相位预算 15n + 512（含 apply_mod 折叠缓冲的 next_size 取整余量与矩阵复合 9(2mx+4)）， 步进循环 8n + 64。对比旧的逐层累加（约 48n）内存占用降至约 1/3
