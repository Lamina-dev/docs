◆ trialdiv_extend_()

void trialdiv_extend_ ( ushort cnt)
static

打包素数，把下标 [1,cnt) 内的奇素数全部收进闭块

参数
cnt<=N 的素数个数，即 lmmp_prime_cnt16_(N) 的返回值（含素数 2）
注解
素数逐个乘进开块，乘积一超过 MAX_T 就闭一块。盖住 cnt 之后，如果 开块乘积还没满，会继续乘到满块才停。故表中存储的均是完整块，块的 划分与 N 无关，扩容永远是纯追加，开块也从不跨调用留存。素数表用尽时 最后一块无法乘满，自动闭合。
