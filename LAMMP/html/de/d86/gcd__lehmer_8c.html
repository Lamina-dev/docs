/ a \ = / A B \ * / a \ \ b / \ C D / \ b /

警告
[a,an] > [b,bn]
注解
不保证返回结果 [a,an] > [b,bn]
返回
a和b是否有一个为0；返回 true 时保证 [a,an] 非零（若 a 先归零 则将 b 移入 a，gcd 即 a）
