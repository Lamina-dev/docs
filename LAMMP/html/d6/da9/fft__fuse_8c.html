fft 蝶形数据面融合内核（两段扫描 + 中点 ch 分解，单次调用完成）

扫描1（j∈[0,l-w)）：D = numa[j] - numb[j] (-scyo 链，起点0) numc[w+j] = (D << shl) 接 shl 移位链（起点0） numa[j] = numa[j] + numb[j] (+acyo 链，起点0) 中点：ch = shlcy1 - (scyo1 << shl) 分解为 chp/chn（scyo1/shlcy1 为扫描1终值） 扫描2（j∈[0,w)）：D2 = numb[l-w+j] - numa[l-w+j] (-scyo 链重置0) numc[j] = (D2 << shl) 接 shl 链（重置0） numa[l-w+j] += numb[l-w+j] (+acyo 链续)

参数
numc蝶形输出系数指针（temp_coef）
numa系数 a 指针（原地加）
numb系数 b 指针（只读）
l系数长度（ms->lenw）
w机器字级移位量（0<=w<=l）
shl比特级左移量
out输出数组（至少 4 个 limb）：out[0]=chp, out[1]=chn, out[2]=shlcy2（扫描2 shl 链移出位），out[3]=(acy_final<<1)|scyo_final
警告
0<shl<64, 0<=w<=l, sep(numc,[numa|numb]), l>0, 各指针非空；实现见 lmmpn/arch/generic/fft_fuse.c（C）与 arch/{x64,arm64}/fft_fuse.S

以 t_i = [numb]>>shr 的逐 limb 流水线（numb 全程只读，不回写移位结果）： 扫描1（i∈[0,w)）：numc[l-w+i] = numa[l-w+i] + t_i (+bcy 链) numa[l-w+i] -= t_i (+acy 链) 扫描2（i∈[0,l-w)）：numc[i] = numa[i] - t'_i (+bcy 链续) numa[i] += t'_i (+acy 链续)，t'_i 从 numb[w] 起算 两段扫描的顶 limb 分别从 numb[w]、numb[l] 取高 shr 位（内核自行加载）

参数
numc蝶形输出系数指针（temp_coef）
numa系数 a 指针（原地加减）
numb系数 b 指针（只读，须有 l+1 个 limb 可读）
l系数长度（ms->lenw）
w机器字级移位量（0<=w<=l）
shr比特级右移量
警告
0<shr<64, 0<=w<=l, sep(numc,[numa|numb]), l>0, 各指针非空；实现见 lmmpn/arch/generic/fft_fuse.c（C）与 arch/{x64,arm64}/fft_fuse.S
返回
打包进位 (acy_final << 1) | bcy_final（acy 为 numa 链，bcy 为 numc 链）
