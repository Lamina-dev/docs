bool lmmp_is_prime_uint_notrial_ ( uint n)

u32 档双基底强伪素数内核（基底 2 + dj_base49 哈希基底，普通域免蒙域算术）

参数
n待判断的数
警告
n>2, n%2==1
注解
建议调用前已过 3,5,7,11 试除（内部不试除）； 供 lmmp_is_prime_uint_ 与 lmmp_is_prime_ulong_notrial_ 的 n≤2^32-1 档共享； 判定集合与 mont63 双链旧实现精确一致（同基底同强 MR 语义）
返回
若 n 为素数，返回 true，否则返回 false
