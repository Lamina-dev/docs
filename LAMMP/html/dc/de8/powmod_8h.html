从梅森折叠积中提取高半积（低位已知变体的 mulhi）

参数
hi结果指针（n 个limb），接收 [q,n]*[mp,n] div B^n
V输入兼工作区（msz 个limb），入口为 q*m mod B^msz-1，出口被破坏
L已知低位（n 个limb），满足 q*m ≡ L (mod B^n)，此处 L = -t_lo mod B^n
n操作数长度
msz折叠尺寸，admissible 且 n <= msz < 2n
警告
sep(hi,V), V 的 msz-n 个高位 limb 亦会被读写
注解
设 P = q*m = hi*B^n + L，则 W = (V-L) mod B^msz-1 = hi*B^n mod B^msz-1， 即 hi 的第 j limb 恰位于 W[(j+n) mod msz]，旋转载出即得
