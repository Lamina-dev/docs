void lmmp_global_deinit ( void )

全局释放函数（线程局部的）

注解
调用此函数将释放库内的所有线程局部持久资源。 此函数多次调用不会导致重复释放。如需要再次使用，请重新调用 lmmp_global_init 初始化。 部分惰性初始化的资源将在再次首次使用时再次初始化，调用此函数可能导致部分缓存失效，导致冷启动和性能下降。
警告
在进程或线程结束时或调用此函数。多线程下，未调用此函数结束线程可能导致内存泄漏。
