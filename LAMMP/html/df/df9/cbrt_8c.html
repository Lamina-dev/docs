计算 [numa,na] * B^(3*nf) 的立方根和余数

参数
dsts立方根结果输出指针（缓冲区长度至少 nf+na/3+3 个limb）
dstr余数结果输出指针（缓冲区长度至少 2*(nf+na/3)+3 个limb，NULL 表示不计算余数）
numa源操作数指针（长度为 na 个limb）
na操作数的 limb 长度
nf精度因子
警告
na>0, numa[na-1]!=0, eqsep(dsts,numa), eqsep(dstr,numa)
注解
if (dstr != NULL) { [dsts],[dstr] = cbrtrem([numa,na]*B^(3*nf))，即精确 floor 立方根 与余数 [numa,na]*B^(3*nf) - [dsts]^3（长度 2*ns+1，ns 为根长） } else { if (nf == 0) { [dsts] = floor(cbrt([numa,na])) } else { [dsts] = [floor|round](cbrt([numa,na]*B^(3*nf))) } }
注意
如你需要精确的floor(cbrt(x))语义，请确保nf==0或传入dstr
