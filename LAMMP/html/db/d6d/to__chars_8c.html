36进制数字字节原地转字符 [dst,n]: [0,35] -> ['0'-'9','a'-'z']或['0'-'9','A'-'Z']

参数
dst输入数字字节数组，同时也是字符输出数组
n字节数组长度
upper大小写选择：true输出大写字母，false输出小写字母
警告
n>=0, dst!=NULL, 0<=dst[i]<=35
注解
原地操作，数值数组转化成字符串

31 {
32 // x>=10 时 c = x + '0' + adj, adj = 'a'-'0'-10 = 39 (小写) / 'A'-'0'-10 = 7 (大写)
33 // -(x>9) 生成全0/全1掩码，与 adj 按位与实现无分支选择
34 const int adj = upper ? 7 : 39;
35 for (mp_size_t i = 0; i < n; i++) {
36 int x = dst[i];
37 dst[i] = (mp_byte_t)(x + '0' + (-(x > 9) & adj));
38 }
39}
