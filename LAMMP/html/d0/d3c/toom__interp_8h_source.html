139 * @param xp2 输出：P(+2^shift) 的结果（n+1 limbs）

146 * @param tp 临时缓存空间（n+1 limbs）
147 * @warning 0<hn<=n, 3<=k, k*shift<LIMB_BITS, sep(xp2,[xp|tp]), sep(xm2,[xp|tp])

168/**
169 * @brief Toom ± 点对配对混合：一次完成和/差半边的右移缩放与重叠拼回
170 * （toom6h/8h 各评估点对的两个 (n+1) 位乘积的后处理）
171 * 输入 [pp,n] 与 (nsign ? -[np,n] : [np,n])，计算：
172 * [np,n] <- ([pp,n]+[np,n])/2^(ns+1)（和半边，供奇系数插值）
173 * [pp,n] <- ([pp,n]-[np,n])/2^(ps+1)（差半边，供偶系数）
174 * 最后 {pp,n+off} <- {pp,n} + {np,n}*B^off
175 * @param pp 输入/输出：正点值乘积（容量 n+off+1 limbs）
176 * @param n 有效数据长度
177 * @param np 输入/输出：负点值乘积（容量 n limbs）
178 * @param nsign np 的符号（非 0 表示 np 存的是负值）
179 * @param off 拼回偏移（limb 数，0<=off<n）
180 * @param ps 和半边附加右移位数
181 * @param ns 差半边附加右移位数
182 * @warning 0<=off<n, ps>=0, ns>=0, pp/np 数据低 ps+1/ns+1 位保证为 0
183 */
184void lmmp_toom_couple_handling_(mp_ptr pp, mp_size_t n, mp_ptr np, int nsign, mp_size_t off, int ps, int ns);
