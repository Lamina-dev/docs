-[np,n] : [np,n])，计算： [np,n] <- ([pp,n]+[np,n])/2^(ns+1)（和半边，供奇系数插值） [pp,n] <- ([pp,n]-[np,n])/2^(ps+1)（差半边，供偶系数） 最后 {pp,n+off} <- {pp,n} + {np,n}*B^off

参数
pp输入/输出：正点值乘积（容量 n+off+1 limbs）
n有效数据长度
np输入/输出：负点值乘积（容量 n limbs）
nsignnp 的符号（非 0 表示 np 存的是负值）
off拼回偏移（limb 数，0<=off<n）
ps和半边附加右移位数
ns差半边附加右移位数
警告
0<=off<n, ps>=0, ns>=0, pp/np 数据低 ps+1/ns+1 位保证为 0
